Project Overview
Nirapod Nibash Bangladesh is a data-driven system designed to manage disaster shelters effectively. This project bridges the coordination gap between citizens, volunteers, and authorities to enhance national disaster resilience.

Key Features (from SRS)
Shelter Management: Real-time registration and monitoring of shelter capacity.

Resource Tracking: Inventory management for food, water, and medical supplies.

Volunteer Coordination: A dedicated interface for volunteer mobilization during emergencies.

Emergency Alerts: A communication system for real-time updates and safety navigation.
